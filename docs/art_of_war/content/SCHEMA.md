# 손자병법 칠판 강의 — 장면 데이터 규격 (`art-of-war-lesson/1`)

이 문서는 **콘텐츠 작성자**와 **재생기 개발자**가 함께 지키는 계약입니다.
`build.mjs`는 `content/*.json`을 파일명 순서로 합쳐 하나의 강의로 만들고, 규칙을 어기면 빌드를 실패시킵니다.

## 파일 구성

| 파일 | 내용 | 작성 |
|---|---|---|
| `00-meta.json` | `schema, lang, eyebrow, title, subtitle, author, source, ui, references, misconceptions, quiz` | 마무리 담당 |
| `01-background.json` | `{ "steps": [...] }` 저자·시대·책의 역사 6단계 | 배경 담당 |
| `02-chapters-a.json` | `{ "steps": [...] }` 제1~6편 | 1~6편 담당 |
| `03-chapters-b.json` | `{ "steps": [...] }` 제7~13편 | 7~13편 담당 |
| `04-closing.json` | `{ "steps": [...] }` 관통하는 생각·오해·오늘의 적용·정리 4단계 | 마무리 담당 |

단계(step) 순서는 파일명 순서 → 배열 순서입니다. 총 23단계(배경 6 + 13편 + 마무리 4).

## 13편 표준 표기 (모든 파일이 똑같이 씁니다)

| 편 | 한자 | 한글 | 한 줄 주제 |
|---|---|---|---|
| 1 | 始計 | 시계 | 싸우기 전에 따져 본다 |
| 2 | 作戰 | 작전 | 전쟁은 비싸고 오래 끌면 해롭다 |
| 3 | 謀攻 | 모공 | 싸우지 않고 이기는 것이 최선 |
| 4 | 軍形 | 군형 | 먼저 지지 않을 형세를 만든다 |
| 5 | 兵勢 | 병세 | 조직과 기세로 힘을 키운다 |
| 6 | 虛實 | 허실 | 약한 곳을 치고 주도권을 쥔다 |
| 7 | 軍爭 | 군쟁 | 유리한 자리를 먼저 차지하는 기동 |
| 8 | 九變 | 구변 | 상황에 따라 원칙을 바꾼다 |
| 9 | 行軍 | 행군 | 지형과 징후를 읽는다 |
| 10 | 地形 | 지형 | 지형별 판단과 장수의 책임 |
| 11 | 九地 | 구지 | 아홉 가지 처지와 사람의 마음 |
| 12 | 火攻 | 화공 | 이로울 때만 움직이고 화는 가라앉힌다 |
| 13 | 用間 | 용간 | 정보가 모든 판단의 시작 |

호칭: 저자는 **손무(孫武)**, 책은 **《손자병법》**(또는 『손자』), 후대 병법가 **손빈(孫臏)** 은 반드시 구별해서 씁니다.

## 단계(step) 공통 필드

```jsonc
{
  "id": "ch01-start",                // 소문자-숫자-하이픈, 전체에서 유일. 편 단계는 ch01-…~ch13-…
  "nav": "제1편 시계",                // 목차 버튼 글자 (12자 이내)
  "part": "background",              // "background" | "chapter" | "closing"
  "chapterNo": 1,                    // part=chapter 일 때만 1~13
  "kicker": "제1편 · 始計 · 계획",     // 칠판 위 작은 제목
  "title": "싸우기 전에 먼저 따져 본다", // 28자 이내
  "han": "始計",                     // (선택) 칠판 머리에 크게 쓰는 한자 제목
  "tag": { "tone": "classic", "text": "원문 풀이" },
                                      // tone: "fact"(사실) | "debated"(학계 논쟁) | "classic"(원문 풀이) | "interp"(현대적 해석)
  "summary": "한두 문장 요약 (90자 이내)",
  "narration": "…",                  // 해설 대본 (아래 규칙)
  "quote": {                         // part=chapter 는 필수, 그 외 선택
    "han": "兵者 國之大事",           // 원문 (한자)
    "reading": "병자 국지대사",       // 한글 독음
    "meaning": "전쟁은 나라의 큰일이다", // 뜻풀이 (원문의 뜻을 벗어나지 않게)
    "where": "제1편 시계"            // 출처 (편 이름)
  },
  "digest": [                        // "한 장 요약": 3~4개. 소리 없이 읽어도 편의 내용이 잡히게
    { "head": "무엇을 말하나", "text": "…(70자 이내)" },
    { "head": "핵심 개념",     "text": "…" },
    { "head": "오늘 읽는 법",   "text": "…" }
  ],
  "callout": { "tone": "info", "title": "…(20자)", "text": "…(120자 이내)" },
                                      // tone: "info" | "warn". 한계·오해·논쟁은 여기에 숨기지 않고 씁니다.
  "legend": [ { "color": "mint", "style": "box", "text": "…" } ],
                                      // style: box | line | dash | dot ; color: white mint yellow pink sky orange
  "alt": "그림을 못 보는 사람을 위한 설명 (200자 이내, 위치·모양·관계를 말로)",
  "beats": [ { "at": 0.02, "text": "자막 한두 문장" } ],
  "board": { "kind": "…", "…": "…" },
  "panel": [ { "text": "칠판에 쓰는 한 줄", "color": "yellow", "size": "m", "at": 0.30 } ]
                                      // 판서 요약 2~5줄. size: xl l m s. 한 줄 28자 이내.
}
```

### 시간 `at`

모든 `at`은 **해설 길이에 대한 비율(0.0~1.0)** 입니다. 해설 음성 길이가 달라져도 판서가 어긋나지 않게 하려는 규칙입니다.
재생기가 `at × (해설 길이)`로 바꿉니다. 같은 배열 안에서 `at`은 오름차순이며, 마지막 요소의 `at`은 0.85 이하로 합니다(판서가 해설보다 먼저 끝나게).
요소의 그리는 시간은 재생기가 글자 수·종류에 따라 정하므로 `dur`는 쓰지 않습니다.
`beats[].at`은 해설의 문장 위치에 맞춥니다. 해설이 N문장이면 beats는 2~5개이고 문장 경계 근처 값을 씁니다.

### 해설(`narration`) 규칙 — 음성 합성(MAI-Voice-2)에 그대로 들어갑니다

- 한국어 구어체 존댓말 ("~해요/~입니다"), **330~430자**(공백 포함). 450자를 넘으면 합성이 실패합니다.
- **한자·로마자·아라비아 숫자·기호(`%`, `→`, `《》`, 괄호) 금지.** 모두 한글로 풀어 씁니다. 예: "기원전 오백육 년", "열세 편", "손빈", "병자 국지대사".
- 원문 인용은 한글 독음으로 읽고 바로 뜻을 풀어 줍니다.
- 모르는 것을 아는 척하지 않습니다. 불확실하면 "전해집니다", "~라고 알려져 있어요", "학계에서는 논쟁이 있어요"로 씁니다.
- 첫 문장은 그 단계의 질문이나 장면으로 시작하고 마지막 문장은 다음 단계로 이어지는 한 줄 정리로 끝냅니다.

### 칠판에 쓰는 글(보드·패널·퀴즈 등)

- 한글은 손글씨체(나눔손글씨 펜), **한자는 내장 부분 글꼴**로 그립니다. 한자는 `han`, `quote.han`, 칠판 노드 제목·줄, 표 칸에 써도 됩니다.
- 칠판 글은 짧게: 노드 제목 ≤ 12자, 노드 줄 ≤ 16자(한 노드 줄 수 ≤ 3), 표 칸 ≤ 14자, 패널 줄 ≤ 28자.
- 해설에 없는 사실을 칠판에만 새로 쓰지 않습니다(칠판은 해설의 요약).

## 보드(`board`) 종류

모든 요소는 `at`(비율)을 가집니다. 좌표 `x, y`는 가상 캔버스 **가로 0~160, 세로 0~100**(16:10)이며 재생기가 화면에 맞춥니다.
가장자리 여백 5를 지키세요: 노드·글이 `5 ≤ x ≤ 155`, `5 ≤ y ≤ 95` 안에 들어와야 하고 노드끼리 겹치면 안 됩니다(빌드가 검사).

### 1. `diagram` — 자유 배치 (지도·그물·순환·결정 갈림길 등)

```jsonc
"board": { "kind": "diagram", "elements": [
  { "type": "region", "x": 8, "y": 10, "w": 60, "h": 40, "color": "sky", "label": "북쪽", "at": 0.02 },
  { "type": "node", "id": "a", "x": 30, "y": 30, "w": 34, "h": 18, "shape": "round",
    "color": "mint", "han": "道", "title": "명분", "lines": ["백성과 한마음"], "at": 0.10 },
  { "type": "link", "from": "a", "to": "b", "style": "solid", "arrow": true, "label": "이어진다", "color": "yellow", "at": 0.30 },
  { "type": "link", "from": [20, 80], "to": [60, 80], "style": "dash", "arrow": true, "at": 0.4 },
  { "type": "text", "x": 80, "y": 90, "text": "※ 거리 비율은 실제와 달라요", "size": "s", "color": "white", "align": "center", "at": 0.6 }
]}
```

- `node.x, y`는 **중심**, `w, h`는 크기. `shape`: `box | round | ellipse | circle | hex`. `han`(선택)은 노드 안쪽 위에 크게 쓰는 한자 1~4자.
- `link.from/to`는 노드 id 또는 `[x, y]`. `style`: `solid | dash`. `arrow` 기본 true. `label`은 ≤ 10자.
- 모든 요소의 `size`: `s | m | l | xl`, `align`: `left | center | right`.

### 2. `timeline` — 연표

```jsonc
"board": { "kind": "timeline",
  "axis": { "from": -800, "to": -200, "step": 100, "unit": "BCE" },      // 음수 = 기원전. 눈금은 "기원전 800" 식으로 표시
  "elements": [
    { "type": "span",  "from": -770, "to": -476, "lane": 0, "color": "sky",    "title": "춘추 시대", "uncertain": false, "at": 0.05 },
    { "type": "event", "year": -506,              "lane": 1, "color": "yellow", "title": "백거 전투", "sub": "오나라의 초나라 공격", "uncertain": true, "at": 0.40 }
  ] }
```

- `lane`은 0~3(위에서 아래). `uncertain: true`면 점선·물음표로 그려 "연대 논쟁"을 시각화합니다.
- 연도는 정수. 한 요소 안에서 `year`/`from`/`to`가 축 범위 밖이면 빌드 실패.

### 3. `ladder` — 계단(상책→하책, 우선순위)

```jsonc
"board": { "kind": "ladder", "top": "상책", "bottom": "하책",
  "elements": [
    { "type": "tier", "han": "伐謀", "title": "계략을 꺾는다", "line": "싸우기 전에 뜻을 무너뜨림", "color": "mint", "at": 0.1 },
    { "type": "tier", "han": "伐交", "title": "동맹을 끊는다", "line": "…", "color": "sky", "at": 0.3 }
  ] }
```

- tier 3~5개. 위쪽이 가장 좋은(우선하는) 단계.

### 4. `radial` — 가운데 하나에서 뻗는 요소들

```jsonc
"board": { "kind": "radial",
  "center": { "han": "五事", "title": "다섯 가지 점검", "lines": ["먼저 따질 것"], "color": "yellow", "at": 0.02 },
  "elements": [
    { "type": "spoke", "han": "道", "title": "도", "line": "백성과 한뜻", "color": "mint", "at": 0.12 }
  ] }
```

- spoke 3~8개, 시계 방향 위쪽부터 균등 배치.

### 5. `table` — 표

```jsonc
"board": { "kind": "table", "cols": ["이름", "뜻", "핵심"],
  "elements": [
    { "type": "row", "cells": ["因間", "그 지방 사람", "현지 정보"], "color": "mint", "at": 0.15 }
  ] }
```

- 열 2~4, 행 3~9, `cells.length == cols.length`.

### 6. `compare` — 둘을 견주기

```jsonc
"board": { "kind": "compare",
  "left":  { "title": "손무", "color": "mint" },
  "right": { "title": "손빈", "color": "orange" },
  "elements": [
    { "type": "pair", "label": "시대", "left": "춘추 말기", "right": "전국 시대", "at": 0.2 }
  ] }
```

- pair 3~6개. `label` ≤ 6자, 칸 글 ≤ 16자.

## 마무리 파일(`00-meta.json`)

```jsonc
{
  "schema": "art-of-war-lesson/1",
  "lang": "ko",
  "eyebrow": "인문 고전 · 손자병법",
  "title": "손자병법 칠판 강의",
  "subtitle": "저자와 시대부터 열세 편의 핵심까지, 23단계",
  "author": "Microsoft Korea STU",
  "source": { "title": "…", "channel": "…", "url": "…", "note": "영상 내용은 확인하지 못했고 …" },
  "ui": { "hint": "눌러서 판서 시작" },
  "references": [ "출처 문자열 …" ],              // 5~10개. 실제로 존재하는 고전·번역·연구만. URL은 확실한 것만.
  "misconceptions": [ { "title": "…", "text": "…" } ],   // 3~5개
  "quiz": [                                                // 6문항
    { "question": "…", "chapterNo": 3,
      "options": [ { "text": "…", "correct": false, "feedback": "…" }, … 3개, 정답 정확히 1개 ] }
  ]
}
```

## 사실 규율 (모든 작성자)

1. **웹 검색·표준 자료로 확인한 것만** 씁니다. 원문 인용은 통행본(무경칠서/조조 주석본) 13편 본문에 실제 있는 구절만 쓰고, 독음·뜻풀이를 정확히.
2. 논쟁이 있는 것(손무 실존·생몰 연대·13편의 성립 시기·일화의 사실성)은 `tag.tone = "debated"`와 `callout`에 **논쟁이 있다고 분명히** 씁니다. 연도를 정확한 것처럼 쓰지 않습니다.
3. 영상 〈절대 지지 않는 법 ─ 《손자병법》 90분 완전 해설〉(인문학이랑)의 **내용은 확인되지 않았으므로** 영상의 발언을 인용하거나 요약한 것처럼 쓰지 않습니다. 영상은 `00-meta.json`의 `source`에서 "영감을 받은 일반 해설"로만 밝힙니다.
4. 현대적 적용은 `tag.tone = "interp"`로 표시해 원문과 구분합니다.
5. 《삼십육계》는 별개의 후대 책이므로 《손자병법》 내용으로 섞지 않습니다. 고유명사·연도·숫자는 확신 없으면 뺍니다.
6. 특정 기업·고객 이름을 쓰지 않습니다.

## 엔진 구현 메모 (필드는 그대로, 동작만 밝혀 둠)

- `quiz[].chapterNo`는 0~13입니다. 1~13이면 "제n편 다시 보기"가 그 편 단계로, 0이면 "배경 다시 보기"가 첫 배경 단계로 이동합니다.
- `diagram`의 `text` 요소는 `y`가 글줄의 **세로 중심**입니다. `tag.text`는 ≤ 16자, 단계 `han`은 한자 사이에 공백 하나가 들어가도 됩니다(예: "兵者 國之大事").
- `references[]`와 `source.url`의 주소는 **눈에 보이는 글자**로만 그립니다(`<a href>` 없음, 오프라인 규칙).
- 좁은 화면(칠판 폭 < 560px)에서는 `diagram`을 줄 단위로 다시 배치하고, `timeline`은 `lane`을 무시한 세로 연표로 다시 그립니다. 판서 순서와 시간(`at`)은 폭과 무관하게 같습니다. 넓은 배치는 칠판 폭 1000px 이상(창 너비 약 1060px 이상)일 때만 씁니다.
- 글자 수 한도(빌드가 검사): 노드 `title` ≤ 12, 표 칸 ≤ 14, 단계 `title` ≤ 28.
